# Bundled writing references

These skills are provided as Markdown references for agents creating social media carousel content in Still Carousel Studio. They contain no executable scripts or runtime code.

- [Carousel Writer](./carousel-writer/SKILL.md) — source: [ClawHub skill page](https://clawhub.ai/social-media-skills/carousel-writer), version 1.0.0, license MIT-0.
- [Hook Writer](./hook-writer/SKILL.md) — source: [ClawHub skill page](https://clawhub.ai/social-media-skills/hook-writer), version 1.0.0, license MIT-0.

Reference files are under each skill’s `references/` directory. The project-specific guide at `/SKILL.md` remains authoritative for this editor’s established writing style, slide format, and output defaults. The generic Hook Writer applies only to a carousel’s cover hook. If no brand or voice files are supplied, follow the user brief and project guidance rather than inventing brand details.
